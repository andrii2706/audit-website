# Палітра «O · Оригінал» — кольори нинішнього сайту bp-audit.com.ua

Встановлення:
1. Розпакувати в корінь проєкту (папка, де лежить `web/`), дозволити заміну.
2. `node web/scripts/apply-palette-original.mjs` — додає підпис «Оригінал»/«Original» у словники
   (без цього кроку нічого не ламається, у перемикачі буде просто «O»).
3. Перезапустити `npm run dev`. У перемикачі внизу зліва з'явиться третя кнопка «O · Оригінал».
   Зробити її палітрою за замовчуванням: `NEXT_PUBLIC_PALETTE=o` у `web/.env.local` (і перезібрати).

## Кольори
Зі старого сайту (HTML головної):  #0080FE акцент · #303030 текст · #4A4A4A · #656565 · #A3A3A3 · білий фон
З логотипа клієнта:                #4CB6DC дуга · #3C8EC8 літери (підсвітки на темному, дуги й точки глобуса)
Похідні (позначені в CSS): світлі відтінки для карток і ліній; глибший синій #006AD1 для кнопок —
білий текст на #0080FE має контраст 3,8:1, а для дрібного тексту треба ≥ 4,5:1.

Фіолетові #714CB6, #533192, #2B1B3C тощо у збереженому HTML — НЕ кольори сайту: їх додало розширення браузера.

## Файли
- `concept/palette-original.css` (новий) — палітра; підключає PaletteSwitcher, тож concept.css не змінюється.
- `concept/PaletteSwitcher.tsx` — третя палітра O (і в скрипті до першого малювання).
- `[locale]/layout.tsx` — `NEXT_PUBLIC_PALETTE` приймає `o`, підпис кнопки. Якщо правили layout самі —
  змініть лише рядок `const PALETTE = …` і проп `labels` у `<PaletteSwitcher …>` (див. файл).
- `e2e/pages.spec.ts` — тест палітри O.
